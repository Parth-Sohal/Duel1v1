This folder holds seed content for challenges (Iteration 2+).

Each challenge is one file (or one folder) containing:

- the statement (markdown)
- starter code per language (JavaScript, Python)
- test cases, each marked `hidden: true/false`
- a reference solution in every supported language

Rules (from `docs/data-model.md`):

- Hidden tests live only here and in the database. They must never be copied into `apps/web/`.
- Every challenge is hand-verified with its reference solutions before being published.
