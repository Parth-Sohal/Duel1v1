# 001 — Product name: Coding Arena

Date: 2026-10-27
Status: accepted

## Context

The project needed a final name before Iteration 0 (`PLAN.md` decision D1). The working name was "Coding Duel".

## Decision

The product is named **Coding Arena**.

## Why

Chosen by the owner. It keeps the arena feel and is clear for sign-in screens, landing pages, and the repo.

## Revisit when

Name collision, trademark concern, or a later rebrand.
